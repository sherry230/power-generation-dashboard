# FineBI 实现说明

本文记录从原始数据到仪表板的实现路径，便于复现和后续维护。项目使用 FineBI（具体版本以原项目环境为准），数据准备可配合 Excel。

## 1. 数据准备

### 1.1 数据表拆分

建议将数据拆成三张主题表，避免一张宽表反复筛选：

| 数据表 | 粒度 | 主要字段 |
|---|---|---|
| `national_annual` | 年 | 年份、总发电量、火电、水电 |
| `province_annual` | 年 / 省 | 年份、地区、发电量 |
| `beijing_monthly` | 月 | 年月、总发电量、火电、水电、核电、太阳能、风力 |

统一字段类型：

- 年份：数值或日期（建议数值，便于排序）；
- 年月：日期（每月 1 日）或 `YYYY-MM` 文本；
- 地区：文本，统一“内蒙古自治区/内蒙古”等简称；
- 发电量：数值，单位统一为**亿千瓦时**；
- 空值：保持为空，不用 0 代替；结构性零值保留 0。

### 1.2 导入 FineBI

1. 打开 FineBI，进入“我的分析”；
2. 新建分析主题；
3. 上传 Excel/CSV 数据表；
4. 检查字段类型，确认数值字段未被识别为文本；
5. 保存并更新数据。

## 2. 计算字段

在 FineBI 中新建以下计算字段：

| 字段 | 公式 | 用途 |
|---|---|---|
| 火电占比 | `火电发电量 / 总发电量` | 结构分析 |
| 水电占比 | `水电发电量 / 总发电量` | 结构分析 |
| 其他电源 | `总发电量 - 火电发电量 - 水电发电量` | 风电/光伏/核电等派生口径 |
| 其他电源占比 | `其他电源 / 总发电量` | 结构分析 |
| 同比增长率 | `(本期 - 上年同期) / 上年同期` | 年度同比；月度同比需补 2022 年数据 |

设置字段格式：

- 发电量：千分位、保留 2 位小数；
- 占比：百分比、保留 1 位小数；
- 同比：百分比、保留 1 位小数；
- 缺失值：显示为“—”，不要显示为 0。

## 4. 仪表板布局

建议采用“总览 + 分区”的结构：

```text
┌──────────────────────────────────────────────┐
│ 标题：全国发电量分析（2014—2023）              │
│ KPI：总发电量｜同比｜火电占比｜其他电源占比      │
├───────────────────────┬──────────────────────┤
│ 全国发电量趋势         │ 火电/水电趋势          │
├───────────────────────┼──────────────────────┤
│ 2021 年省份排名        │ 关键结论 / 注释        │
├───────────────────────┴──────────────────────┤
│ 标题：北京市发电量分析（2014—2023）            │
│ 北京年度趋势｜北京月度趋势｜电源结构｜重点省份   │
└──────────────────────────────────────────────┘
```

布局原则：

1. 第一屏放总量、增速、结构三类 KPI；
2. 趋势图放左侧，排名/结构图放右侧；
3. 文字结论不超过 3 条，放在图表旁边；
4. 统一颜色：火电用暖色、水电用蓝色、其他电源用绿色；
5. 每张图下方标注数据来源、单位、更新时间。

## 5. 交互与发布

建议增加以下筛选器：

- 年份；
- 地区；
- 电源类型；
- 数据口径/单位说明。

发布前检查：

- 过滤器是否影响所有相关组件；
- 图表标题是否为业务语言，而不是“任务4.x”；
- 单位是否统一；
- 零值与空值是否被正确区分；
- 是否标注数据来源和更新时间；
- 移动端/投屏比例是否可读。

## 6. 复现注意事项

- 原始数据已放在 `data/source/`，处理结果在 `data/processed/`；
- Q4 数据已补齐 31 省，`q4_2023_top10.csv` 为 2023 Q4 汇总排名；
- 太阳能列单位疑似“万千瓦时”，不要直接与“亿千瓦时”总量相加；
- 北京核电为结构性零值，不应作为缺失值删除；
- 北京本地发电量不等于全社会用电量，不要用本地发电量直接推断用电需求。
