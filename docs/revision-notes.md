# 修订说明

本文件记录从初版项目材料到作品集版本的改动，便于面试时说明“我做了什么优化”。

## 1. 结构：从操作教程改为分析交付

初版报告的主线是 FineBI 安装、图表制作和仪表板搭建，读起来更像课程作业。修订版改为：

```text
业务背景 → 分析问题 → 数据与口径 → 方法 → 核心发现 → 结论与建议 → 局限 → 附录
```

FineBI 操作步骤被移到 [`finebi-implementation.md`](finebi-implementation.md)，不再占用主报告篇幅。

## 2. 结论：把“绝对化表述”降级为“证据匹配的表述”

| 初版表述 | 修订后 | 原因 |
|---|---|---|
| 火电相较水电发展形势好 | 火电仍是增量主体，但份额下降 9.7 个百分点 | 绝对量增长不等于结构更优；份额才是结构指标 |
| 2017 年北京下降是环保政策、电源结构、外受电通道导致的 | 上述因素是待验证的解释假设，暂不作为因果结论 | 初版未附政策、装机、外受电数据 |
| 2021 年前十省份多在中西部、人口密度低 | 资源禀赋与负荷中心并存，不能仅用人口密度解释 | 广东、山东、江苏等负荷中心也在前十 |
| 2023 年 Q4 前十省份 | 初版只展示 4 省；本次用 31 省月度表重算 Q4 前十 | 初版图表与标签不一致 |
| 北京 2023 年 10 月为 25.7 | 源表为 25.2；Q4 合计 124.4 | 以源表为准 |
| 北京 7 月、12 月双峰是因为空调和供暖 | 描述季节形态，机制需要气温、供暖、外受电数据验证 | 本地发电量不等于用电量 |

## 3. 数据：把“口径问题”显性化

- 统一使用“亿千瓦时”；
- 将“其他电源”定义为“总发电量 − 火电 − 水电”，并注明是派生口径；
- 区分结构性零值（北京核电）与缺失值；
- 标注时间范围不一致：全国 2014—2023、北京年度 2014—2021、月度数据 2022—2023；
- 用 31 省 2022—2023 月度表重算 2023 Q4 前十，补齐同比；
- 明确“太阳能”列单位疑似“万千瓦时”，不用于总量计算。

## 4. 图表：重新制作，统一视觉与标注

- 全国总量、火电/水电、省份排名、北京年度、北京月度、2023 Q4 共 6 张图重新绘制；
- 使用统一字体、颜色和网格线；
- 线图不再从 0 基线开始，突出趋势变化；
- 排名图按降序排列，第一名在顶部；
- 图表标题改为业务语言，不使用“任务4.x”；
- 保留原仪表板截图作为整体预览。

## 5. 交付：从单个 PDF 变为可复现仓库

新增：

- `README.md`：项目概览、关键发现、目录与复现入口；
- `docs/analysis-report.md`：可在线读的完整报告；
- `docs/finebi-implementation.md`：数据准备、计算字段、图表和看板搭建；
- `docs/data-quality-checklist.md`：发布前检查清单；
- `data/README.md`：字段字典、数据来源与已知问题；
- `.gitignore`：避免误传原始数据和临时文件。
